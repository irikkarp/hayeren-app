# Видение продукта

## Идея
Приложение для изучения армянских слов.

## Целевая аудитория
1. **Русскоязычные релоканты в Армении.** Армянский с нуля, алфавит незнаком. Нужна практичная бытовая лексика: магазин, рынок, такси, аренда жилья, кафе, врач, банк, вежливые фразы, числа и цены.
2. **Армяне из России.** Часто понимают или немного говорят на слух, но не читают армянский алфавит. Им особенно важно научиться читать и связать знакомые на слух слова с написанием.

Общее для обеих групп: язык интерфейса русский, нужен **восточноармянский** (литературный язык Армении), обязательна транслитерация и обучение алфавиту.

## Ключевые функции (черновик)
- Карточки слов: армянское написание, транслитерация, перевод, пример
- Интервальные повторения (SRS)
- Тематические наборы слов
- Прогресс и серии дней
- Обучение алфавиту

## Технические решения
- **Платформа:** сначала веб-приложение (PWA, работает офлайн), потом оборачиваем в мобильное приложение для iOS и Android через Capacitor.
- **Стек (по умолчанию):** TypeScript + React + Vite, PWA через `vite-plugin-pwa`. Данные о прогрессе хранятся локально (IndexedDB), без бэкенда в MVP.
- **Тесты:** Vitest (unit) + Playwright (e2e).
- **Хостинг:** бесплатный статический хостинг (GitHub Pages / Netlify / Vercel) — выбрать при деплое.
