# QA: «счётчик не обновляется, показывает 0/15»

Дата: 2026-10-24. Сайт: https://irikkarp.github.io/hayeren-app/ и локальная сборка (`vite preview`). Viewport: iPhone 13 (Playwright, Chromium). Скриншоты: `docs/qa/screens/bug-counter-*.png` (в полностраничных снимках таб-бар «плавает» посередине — артефакт fullPage, не баг).

## Вердикт

**Дефекта нет — поведение по требованиям, но пользователю непонятно (UX-проблема).** Продуктовый код и e2e не менялись; test.fail() не добавлялся.

## Воспроизведение (сайт и локальная сборка дали одинаковый результат)

Онбординг → «Приветствия и вежливость» → на каждой карточке «Показать ответ» → «Знаю».

| Место | Что видно |
|---|---|
| Сессия | 10 карточек, а не 15 (лимит 10 новых слов в день). Тост: «Знаю · вернёмся к слову через 2 дня» |
| Итог сессии | «Хорошая работа!», Пройдено 10 / Знаю 10 / Не знаю 0, «Серия растёт: 1 день подряд», кнопки «К темам», «Учить ещё 10 новых слов». Про «выучено» и про то, что слова сохранены, ничего нет |
| Главная, тема | «выучено 0 из 15», прогресс-бар пустой (`aria-valuenow=0`, width 0%) |
| Плитка «Выучено» | 0 из 88 |
| Плитка «Повторить сегодня» | 0 слов, кнопка «Повторить (0)» неактивна, подпись «На сегодня всё повторено» |
| После перезагрузки | то же самое: данные сохранены, только счётчик «выучено» их не отражает |
| Серия | «1 день подряд» — единственный видимый признак прогресса |

Рабочая проверка сохранения: после 15 слов (10 + «Учить ещё 10») на дне 2 «Повторить» = 15; на дне 6 после ответов «Выучено 15 из 88», тема 15/15; на дне 14 всё остаётся 15/15.

## Анализ

- После первого «Знаю» слово попадает в коробку 2 (срок +2 дня). «Выучено» = коробка ≥ 4 (кр. 7–8, ред. 9). Минимальный путь: день 0 (коробка 2) → день 2 (коробка 3) → день 6 (коробка 4). Раньше шестого дня счётчик «выучено» не может быть больше 0 — это следствие требований, не потеря данных.
- Не причины: сохранение (перезагрузка не теряет), пересчёт (на дне 6 корректно 15), кэш service worker (локальная и живая версии ведут себя одинаково; хэши бандлов отличаются из-за разных base-путей сборки, на поведение это не влияет).
- Проявление «даже если отметил, что знаю все»: в сессии только 10 из 15 слов, оставшиеся 5 остаются «новыми» (до «Учить ещё 10 новых слов»).
- Слова в коробках 1–3 не видны нигде на главной: нет ни «в изучении», ни частичной заливки бара. Слово «выучено» в продукте встречается там, где пользователь ждёт «пройдено». Статус «учу» есть только на экране своего набора (кр. 80), но не в темах.
- Итого: у пользователя после сессии нет подтверждения прогресса, кроме серии. Ощущение «ничего не записалось» закономерно.

## Предложения (без изменения кода; решение за продуктом)

1. Главная, строка темы: «выучено X · в изучении Y из N» (например «выучено 0 · в изучении 10 из 15»); двухцветный прогресс-бар (тёмный — выучено, светлый — в изучении). Критерии 6 и 38 («выучено X из N») придётся уточнить.
2. Плитка «Выучено»: добавить подпись «в изучении N» (сейчас «из 88»).
3. Итог сессии: строка «Новых слов в изучении: 10. Выученным слово станет после повторений через 2, 4 и 8 дней; первое повторение — послезавтра (21 окт.)». Добавить, когда в теме остались неначатые слова: «Осталось 5 новых слов».
4. «Повторить сегодня»: при 0 показывать дату ближайшего повторения («следующее повторение — послезавтра»), вместо одного «На сегодня всё повторено».
5. Единые термины: «выучено» оставить для коробки ≥ 4, на онбординге/первой сессии одной фразой объяснить схему «слово возвращается через 2, 4, 8 дней, после этого оно выучено».
