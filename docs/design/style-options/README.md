# Варианты визуального стиля Hayeren

Структура экранов везде одинакова (см. `docs/design/001-mvp.md`), меняется только визуальный язык. В каждом HTML: мини-мудборд (палитра с hex, шрифты, орнамент, птицепись, значки тем), три экрана 360 px (главная с кнопкой «Повторить (N)» над «Темами», лицевая сторона карточки со словом շնորհակալություն в одну строку, «Тема выучена»), переключатель светлой и тёмной темы. Файлы самодостаточные, открываются двойным кликом. Шрифт Noto Sans Armenian берётся локально, при его отсутствии подтягивается из `app/node_modules`, иначе системный армянский.

| Файл | Иконка |
|---|---|
| `option-a.html` | `icon-a.svg` |
| `option-b.html` | `icon-b.svg` |
| `option-c.html` | `icon-c.svg` |

Общее для всех: птицепись (Ա в виде птицы) в логотипе, заголовке «Алфавит», празднике и иконке; вместо огонька серии растёт гранат (A, C) или абрикосовое дерево (B); орнамент только в шапке, пустых состояниях и празднике, учебный экран чистый. Контраст текста не ниже AA, тач-зоны от 44 px, статусы не только цветом (галочка и текст).

## A. «Рукопись»
Пергамент, гранат, золото, шрифт с засечками (Noto Serif Armenian) для заголовков и слова. Тонкая золотая линия, аревахач в шапке, хачкар как разделитель, птицепись с тонкими перьями в духе миниатюр.
- Плюсы: самый «книжный» и спокойный, хорошо поддерживает ощущение серьёзного изучения; армянская буква в засечках выглядит аутентично.
- Риски: менее «ярко» по сравнению с запросом; засечный армянский требует проверки шрифта в сборке (запасной Noto Sans Armenian); золото только как декор, текстом использовать нельзя (контраст).

## B. «Современный Ереван»
Розовый туф, абрикос, гранат, Арарат-синий; плоские цвета, жирные тёмные контуры и «жёсткие» тени, зигзаг туфовых фасадов, плитки тем яркими квадратами. Серия: абрикосовое дерево.
- Плюсы: самый яркий и молодой, простой в реализации (чистый CSS и плоский SVG), отлично читается; мало риска по контрасту.
- Риски: орнаментальность слабее, армянская тема выражена цветом, а не узором; жирные контуры и тени при росте числа элементов могут «шуметь».

## C. «Ковёр»
Поле глубокого синего Арарата с решёткой, светлые панели с абрикосовой двойной рамкой, килимная кайма, восьмиугольные медальоны-гюли для тем, ступенчатые уголки карточки, угловая птицепись из прямых линий. Серия: гранат, чьи зёрна «созревают».
- Плюсы: самый насыщенный и узнаваемо армянский; геометрия лёгко масштабируется и хорошо ложится в SVG; слово всегда на светлой панели с максимальным контрастом.
- Риски: больше орнамента, нужна дисциплина (только шапка, пустые состояния, праздник); большая площадь тёмно-синего поля, в тёмной теме различие поля и панелей надо проверять на реальных экранах; ромбовидные кнопки (clip-path) требуют аккуратной реализации фокуса.

## Что согласовать
1. Выбор варианта (или смесь, например палитра B с орнаментом C).
2. Метафора серии: гранат или абрикосовое дерево.
3. Птицепись остаётся декором: на всех 38 буквах алфавита птиц не рисуем (только Ա и, при желании, заглавные буквицы).
4. Иконка приложения: после выбора доработать под размеры 48 и 192 px (проверить читаемость).
