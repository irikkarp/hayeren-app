# Дизайн 001 — MVP: карточки, повторение, свои слова, экспорт

Основание: `docs/requirements/001-mvp.md`, редакция 4, критерии приёмки 1–123. Визуальный стиль: A «Рукопись» (выбран владельцем 2026-10-19). Компоненты, токены, типографика, орнамент: `docs/design/ui-kit.md`. Прототипы: `docs/design/prototypes/screens.html` (открыть в браузере; кнопка вверху справа переключает тему авто / светлая / тёмная). Иконка: `docs/design/icon.svg`. SVG-ресурсы (птица, хачкар, гранат, узор, значки тем): `docs/design/assets/`.

В тексте «(кр. N)» означает критерий приёмки N. Идентификаторы экранов `S01…S14` и диалогов `D1…D6` используются в таблице покрытия в конце.

## 1. Карта экранов и навигации

### 1.1. Схема

```
Первый запуск
  S01 Онбординг ──(выбор режима)──▶ S02 Главная

Нижняя навигация (3 вкладки, видна только на корневых экранах)
  ├─ Главная  S02 ──▶ «Повторить (N)» ──▶ S03 Сессия (общая) ──▶ S04 Итог ──▶ «Повторить ещё (K)» ──▶ S03
  │             │
  │             └──▶ тема ──▶ S03 Сессия ──▶ S04 Итог (или S04b «Тема выучена»)
  │                    │            └─ очередь пуста с самого начала ──▶ S05 Нет карточек
  │                    └─ набор ──▶ S08 Набор ──▶ S03 Сессия
  │                                    ├─ слово ──▶ S12 Форма (изменить) ── D4 Удалить слово
  │                                    ├─ Добавить слова ──▶ S09
  │                                    ├─ Переименовать ── D5
  │                                    ├─ Экспортировать набор ──▶ тост T1/T2
  │                                    └─ Удалить набор ── D3
  │               «Добавить слова» ──▶ S09 Способ добавления
  │                                     ├─ Вставить список ──▶ S10 ──▶ S11 Предпросмотр ──▶ (сохранение) ──▶ S08
  │                                     ├─ Добавить по одному ──▶ S12 Форма (добавить) ── D6 Дубликат
  │                                     └─ Импорт из файла ──▶ S13 Выбор файла ──▶ S14 Колонки ──▶ S11
  ├─ Алфавит   S06
  └─ Настройки S07 ── D2 Сброс прогресса; Экспорт ──▶ T1/T2
```

### 1.2. Навигация

Три вкладки внизу: «Главная», «Алфавит», «Настройки» (обоснование и вид: ui-kit, раздел 5). На экранах S03–S05 (включая S04b), S08–S14 вкладки скрыты, вверху стрелка «‹» (кроме S03: кнопка «Завершить»). Системная кнопка «Назад» на Android и жест на iOS работают как «‹». На S03 системная «Назад» равна «Завершить» (ответы уже сохранены, подтверждение не нужно).

### 1.4. Общие правила

- Язык интерфейса русский. Армянский текст: шрифт `font-hy`, шкала `hy-*`, атрибут `lang="hy"` (кр. 5). Шрифт входит в сборку, внешних запросов нет.
- Работает без сети. Никаких состояний «нет соединения» не нужно (кр. 28).
- **Склонения.** Везде, где подставляется число: «слово / слова / слов», «набор / набора / наборов», «день / дня / дней», «строка / строки / строк». Правило: n mod 100 от 11 до 14 → третья форма; иначе n mod 10 = 1 → первая; 2–4 → вторая; остальное → третья. «выучено X из N» не склоняется.
- **Баннер B1 «хранилище недоступно»** (кр. 30): при недоступном IndexedDB под верхней панелью (над содержимым) на всех экранах закреплён `banner-warn` с текстом «Прогресс не сохранится: браузер запрещает хранение данных». Не закрывается. На S01 тоже.
- **Ошибка загрузки данных** (редкий случай, не покрыт критериями): вместо экрана `banner-err` «Не удалось открыть данные приложения. Обновите страницу.» и кнопка «Обновить».
- **Загрузка при старте:** пока читаются настройки (обычно доли секунды), показывается пустой фон `bg` с названием «Hayeren». Если дольше 300мс, каркас-скелетон экрана. Онбординг не мигает: пока настройки не прочитаны, экран не выбирается (кр. 4).

## 2. Экраны

### S01. Онбординг

**Кр.:** 1, 2, 3, 4, 5. **Прототип:** `screens.html`, блок S01.

**Назначение.** Один раз спросить режим занятий.

**Структура (сверху вниз), без вкладок и верхней панели:**
1. Шапка-«буквица» (ui-kit 6.16, 8): фон `header-bg` с узором аревахач (прозрачность 0.35), по центру птицеписное `Ա` 104px (декор, `aria-hidden`), под ним «Hayeren» (`t-display`, это `h1`), `Հայերեն` (`hy-body`, `aria-hidden`), подпись «Армянские слова за 5–10 минут в день». Птица здесь играет роль украшенной первой буквы книги. Это единственное место с большой птицей до экрана «Тема выучена».
2. Заголовок «Как вы хотите заниматься?».
3. Две крупные кнопки-карточки (весь блок нажимаемый, высота по содержимому, минимум 88px), одна под другой:
   - «Учу армянский с нуля». Описание: «Под каждым словом будет транслитерация латиницей». Пример `բարև · barev`.
   - «Понимаю на слух, хочу научиться читать». Описание: «Транслитерация скрыта, её можно подсмотреть по кнопке». Пример `բարև · ?`.
4. Мелкий текст «Режим можно поменять в настройках».

**Действия.** Нажатие на любую карточку сразу сохраняет режим (`beginner` или `reader`) и открывает S02 (без отдельной кнопки «Продолжить»). Выбранный по умолчанию режим не подсвечивается: пользователь делает осознанный выбор.

**Состояния.** Обычное; B1 при недоступном хранилище (выбор работает в рамках сессии); ошибка записи настроек: `banner-err` «Не удалось сохранить выбор. Попробуйте ещё раз».

**Повторный запуск (кр. 4).** Если режим сохранён, S01 не показывается, открывается S02.

### S02. Главная

**Кр.:** 6, 7, 8, 14, 23, 24, 25, 26, 38, 39, 30, 110–114, 120, 121. **Прототип:** блоки «S02 Главная», «S02 Главная, первый запуск», «S02 Кнопка «Повторить (N)»: четыре состояния».

**Назначение.** Показать прогресс, дать одним нажатием повторить всё, что пора, и выбрать, что учить.

**Структура сверху вниз** (вкладка «Главная» активна):
1. **Шапка** (ui-kit 6.16): фон `header-bg` с узором аревахач, слева птицеписное `Ա`, справа «Hayeren» (`h1`) и `Հայերեն`. Прокручивается вместе с контентом.
2. **Серия: плитка с растущими гранатами** (кр. 23–26; ui-kit 6.5). На всю ширину. Слева до пяти гранатов по возрастанию размера, справа заголовок «N дня/дней/день подряд» и подпись «Гранат растёт: до спелого K дня/дней». Серия 0: один штриховой контур, заголовок «Начните серию сегодня», подпись «Ответьте на любую карточку, и вырастет первый гранат». Серия 5 и больше: «Гранат созрел». Логика серии (кр. 24–26: вчерашний ответ без сегодняшнего сохраняет число) дизайн не меняет; число берётся как есть и без пометок.
3. **Две плитки статистики в ряд** (кр. 23):
   - «Выучено»: число выученных (box ≥ 4) и «из <88 + число своих слов>».
   - «Повторить сегодня»: число слов, у которых `dueDate ≤ сегодня` (встроенные и свои), подпись «слов» в нужной форме. Равно N на кнопке ниже (кр. 112).
4. **Кнопка «Повторить (N)»** (кр. 110): под плитками, над разделом «Темы», `primary`, на всю ширину (ui-kit 6.17). Состояния:
   - N от 1 до 30: активная кнопка, без подписи.
   - N больше 30: активная кнопка и под ней подпись «В сессии 30 слов, остальные — в следующей» (кр. 114).
   - N = 0 и ещё нет ни одного слова с прогрессом: кнопка недоступна (`disabled`, видна), под ней постоянный текст «Пока нечего повторять: начните с любой темы» (кр. 113).
   - N = 0, прогресс есть: кнопка недоступна, текст «На сегодня всё повторено» (кр. 113).
   Текст связан с кнопкой через `aria-describedby`. Нажатие запускает общую сессию (S03, маршрут `/session/review`). Если к моменту нажатия очередь пуста (кр. 120): сессия не открывается, значения на экране обновляются, сообщений нет.
5. Раздел «Темы» (`t-head` с тонкой линией): 6 строк в порядке `order` (кр. 6). Строка: слева значок темы в плитке (ui-kit 6.18), название, «выучено X из N», полоса прогресса. Строка целиком — кнопка, запускает сессию по теме (кр. 14). Тема, где у всех слов `box ≥ 4`, получает плашку «✓ Выучена» справа вместо шеврона (кр. 8). У пользователя без прогресса везде «выучено 0 из N», пустая полоса, без сообщений (кр. 7). Запуск полностью выученной темы работает как раньше (S05a, кр. 121).
6. Раздел «Мои наборы» с заголовком и кнопкой-ссылкой «+ Добавить слова» справа (кр. 38–39). Наборы, новые сверху. Строка набора без значка и состоит из двух тач-целей: слева текстовая часть (название, «выучено X из N» или «0 слов», полоса прогресса) открывает S08; справа кнопка «Учить» (`secondary`, малая) запускает сессию (кр. 14). У набора без слов кнопки «Учить» нет (кр. 43). Ограничение: см. вопрос 1.
7. Нижняя навигация.

**Пустое состояние «Мои наборы»** (нет наборов, кр. 38): карточка с хачкаром (`gold`, декор), текстом «Добавьте слова, которые дал учитель» и кнопкой `primary` «Добавить слова» (прототип «S02 Главная, первый запуск»).

**Действия и переходы.** «Повторить (N)»: общая сессия S03. Тема: S03. «Учить» у набора: S03. Тело строки набора: S08. «Добавить слова» (в заголовке или в пустом состоянии): S09.

**Состояния.** Загрузка (скелетон плиток и строк); B1; N = 0: см. пункт 4 (раскладка не меняется). N и плитка «Повторить сегодня» обновляются при возврате на главную после сессии, после изменений слов и наборов, после сброса прогресса и при смене даты на устройстве (кр. 112).

### S03. Сессия: карточка

**Кр.:** 9, 10, 11, 12, 13, 14–21, 42, 54, 87. **Прототип:** блоки S03a, S03b, S03c.

**Назначение.** Показать слово, дать открыть ответ, принять оценку.

**Верхняя панель сессии:** слева «Завершить» (текстовая кнопка 44px), по центру «Осталось: N» (N = число карточек в очереди, включая текущую и ещё не показанные повторы), справа пустое место. Ниже полоса прогресса сессии (пройдено / всего в очереди на данный момент; текстовая подпись «Осталось: N» уже даёт число, `aria-label` у полосы: «Пройдено X из Y»).

**Лицевая сторона** (ui-kit 6.2):
1. Плашка: «Новое слово» / «Повторение» / «Ещё раз» (слово вернулось после «Не знаю» в этой же сессии).
2. Армянское слово (`hy-hero`).
3. Режим `beginner`: транслитерация под словом (кр. 9); у авто-транслитерации справа плашка «авто» (кр. 54).
   Режим `reader`: транслитерации нет; кнопка «Подсказка» (`secondary`, малая). Нажатие показывает транслитерацию (и плашку «авто» при необходимости) только на этой карточке; кнопка исчезает. На следующей карточке снова скрыта. Переключение режима в настройках применяется к следующей показанной карточке (кр. 34).
4. Перевода и примера нет (кр. 12). Метка `needs_review` не показывается (кр. 13).
5. Нижняя панель сессии: **только** кнопка «Показать ответ» (`primary`). Кнопок «Знаю» / «Не знаю» на лицевой стороне нет вообще (кр. 11: они появляются только после ответа). Кнопки «Пропустить» нет. Звука нет: кнопка с динамиком не рисуется (в `option-a.html` она была и убрана). Высота панели одинакова на обеих сторонах (92px), поэтому раскладка при показе ответа не прыгает.
6. Украшение: только тонкая золотая рамка внутри карточки; птицы, хачкара и узора на лицевой стороне нет (ui-kit 6.2, 8.2).

**Обратная сторона** (после «Показать ответ»): армянское слово, транслитерация (во всех режимах, с «авто» если нужно), разделитель-хачкар 28px, перевод (24px жирный), блок «Пример» с армянской фразой и переводом. Если у слова нет примера, блока нет (кр. 87). «Показать ответ» исчезает, на её месте строка из двух кнопок: слева «↺ Не знаю», справа «✓ Знаю» (кр. 10, 11).

**Обратная связь на ответ** (тост над кнопками, 4 секунды, не блокирует следующую карточку; слово с интервалом по таблице алгоритма, кр. 15–18):
- «Знаю»: «Знаю · вернёмся к слову завтра» (интервал 1 день), «…через 2 дня», «через 4 дня», «через 8 дней», «через 16 дней».
- «Не знаю» (первый ответ в сессии): «Не знаю · покажем ещё раз в конце».
- Повторный ответ на ту же карточку в этой сессии (состояние не меняется, кр. 18): «Знаю · слово вернётся завтра» или «Не знаю · слово вернётся завтра».

Цвет не единственный признак: тосты нейтральные, смысл в тексте и значках на кнопках.

**Очередь.** Формирование по кр. 14 (логика у программиста): сначала слова к повторению, затем новые. Слова, у которых после «Не знаю» назначен показ в конце, получают плашку «Ещё раз». **Общая сессия** («Повторить (N)», кр. 115–117): очередь только из слов к повторению, до 30, без новых слов; визуально карточка и ответы те же, отличий в интерфейсе нет (плашка «Повторение» на всех карточках, плашки «Новое слово» не бывает). Слова разных тем идут вперемешку, названия темы на карточке не показываем.

**Завершение.** «Завершить» в любой момент: ответы уже сохранены (кр. 20, 118), переход на S04 (см. вопрос 4). Когда очередь опустела: S04 (кр. 21, 118) или S04b. Закрытие вкладки ничего не теряет.

**Клавиатура на десктопе** (необязательно): Пробел / Enter — «Показать ответ»; стрелка вправо — «Знаю»; влево — «Не знаю».

**Состояния.** Слово удалено из набора во время сессии (кр. 82): пропускается без сообщения. Ошибка записи ответа: `banner-err` над кнопками «Не удалось сохранить ответ. Он будет учтён только до конца сессии.» (экстренный случай, как при B1).

### S04. Итог сессии

**Кр.:** 20, 21, 26, 116, 118, 119. **Прототип:** блок «S04 Итог общей сессии»; вариант с «Тема выучена»: блок «S04b».

**Структура:** без вкладок, по центру колонки. Хачкар 48px (`primary`, декор), заголовок «Хорошая работа!» (`t-title`; при «Завершить» до конца очереди: «Сессия остановлена»), три плитки-итога в ряд «Пройдено», «Знаю», «Не знаю» (число и подпись; кр. 21), строка серии: «Серия: 4 дня подряд» (если сегодня серия выросла: «Серия растёт: 4 дня подряд»; если 0 после сброса: не показывается). Кнопки зависят от того, откуда сессия:

| Сессия | Основная кнопка | Вторая кнопка |
|---|---|---|
| По теме или набору (кр. 21) | `primary` «К темам» (→ S02) | если лимит новых слов исчерпан и в теме или наборе остались новые: `secondary` «Учить ещё 10 новых слов» (вопрос 3, решён) |
| Общая «Повторить (N)», остались слова (K > 0, кр. 119) | `primary` «Повторить ещё (K)», над ней строка «Осталось повторить: K» | `secondary` «На главную» (→ S02) |
| Общая, слов не осталось (K = 0) | `primary` «На главную» | нет |

K равно значению N на главной после сессии (кр. 119): слова, на которые ответили «Не знаю», получают `dueDate` завтра и в K не входят. Если K больше 30, в «Повторить ещё (K)» остаётся число K, а строкой ниже `t-small`: «В сессии 30 слов, остальные — в следующей» (та же формулировка, что на главной, кр. 114).
