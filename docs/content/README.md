# Учебный контент

## `words.json`

Стартовый словарь MVP: восточноармянский язык (литературная норма Республики Армения, реформированная орфография).

Структура файла:

- `version` — версия контента (целое число; увеличивается при изменении слов, чтобы приложение могло обновить словарь, не потеряв прогресс).
- `language` — `hy-east`.
- `translit_scheme` — идентификатор схемы транслитерации (`hayeren-latin-v1`, описана ниже).
- `topics[]` — темы: `id`, `title_ru`, `order`.
- `words[]` — слова:

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Стабильный ID `<topic>-NN`. **Никогда не меняется и не переиспользуется**: к нему привязан прогресс пользователя. |
| `topic` | string | ID темы из `topics[]` |
| `hy` | string | Армянское написание (слово или устойчивая фраза) |
| `translit` | string | Транслитерация по схеме `hayeren-latin-v1` |
| `ru` | string | Перевод на русский; уточнение — в скобках |
| `pos` | string | Часть речи: `noun`, `verb`, `adj`, `adv`, `num`, `pron`, `interj`, `phrase` (устойчивое выражение) |
| `example_hy` | string | Пример употребления (армянская пунктуация: `։` — точка, `՞` — вопросительный знак над ударным гласным) |
| `example_ru` | string | Перевод примера |
| `needs_review` | boolean | `true` — аналитик не уверен в написании, транслитерации или примере; нужна проверка носителем языка |

Итого: 88 слов в 6 темах, 5 помечены `needs_review`.

## Схема транслитерации `hayeren-latin-v1`

Латиница (по правилу проекта в `CLAUDE.md`), ориентирована на **произношение** восточноармянского, но буквы отображаются однозначно, кроме отмеченных случаев. Цель — чтобы русскоязычный пользователь мог прочитать слово вслух, а каждой армянской букве соответствовало постоянное сочетание латинских букв.

### Правила

1. **Апостроф `'` = придыхание.** Пары `p/p'`, `t/t'`, `k/k'`, `ch/ch'`, `ts/ts'` — это разные армянские буквы. Пользователю можно объяснить: со знаком `'` — звук «с выдохом».
2. **Сочетания с `յ`** пишутся буквально: `յա` → `ya`, `յու` → `yu`, `յո` → `yo` (`հարյուր` → `haryur`, `սենյակ` → `senyak`).
3. **Непроизносимый (неписьменный) `ը` показывается как `ə`**, если он звучит в нормативном произношении, но не пишется: `խնդրեմ` → `khəndrem`, `բնակարան` → `bənakaran`, `դրամ` → `dəram`. Это помогает правильно произнести слово; на экране чтения это единственное место, где транслитерация «добавляет» звук, которого нет в написании.
4. **Ե и Ո в начале слова** читаются как `ye` и `vo` — правило применяется к каждому слову фразы отдельно (`խնդրում եմ` → `khəndrum yem`). В быстрой речи вспомогательный глагол `եմ/ես/է/եք` часто звучит как `em/es/e/ek'` — схема этого не отражает ради единообразия.
5. **Ударение не обозначается** (в армянском почти всегда на последнем слоге).
6. Фразы транслитерируются по словам через пробел; армянская пунктуация (`՞`, `։`) в транслитерацию не переносится.
7. Регистр: транслитерация всегда в нижнем регистре.

### Известные ограничения

- `ե` (не в начале слова) и `է` обе дают `e` — обратное преобразование неоднозначно.
- Вставка `ə` (правило 3) — фонетическая, требует проверки носителем; слова с сомнительной вставкой помечены `needs_review`.

## Что помечено `needs_review` и почему

| ID | Слово | Сомнение |
|---|---|---|
| greetings-05 | ցտեսություն | Вставка `ə` в начальном сочетании `ցտ` (`ts'ətesut'yun`) |
| numbers-13 | դրամ | `dəram` по правилу 3, хотя в русскоязычной среде привычно «драм» |
| transport-06 | աջ | Пример «Թեքվեք աջ։» — естественность порядка слов для указаний таксисту |
| transport-10 | կանգնեք | Вставка `ə` (`kangənek'`) и выбор формы: `կանգնեք` vs разговорное `կանգնեցրեք` для «остановите машину» |
| housing-10 | լույս | Пример «Լույսը գնաց։» в значении «отключили свет» — разговорное употребление |

Перед релизом весь словарь желательно вычитать носителю восточноармянского, не только помеченные слова.
